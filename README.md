# input-police-deamon

**Windows 用の「日本語入力・取り締まり」常駐アプリ。**
主に Vim ユーザー向けに、IME（日本語入力）の状態を裏で常時監視し、意図しない全角文字・カタカナ入力を強制的に矯正します。また、Vim でノーマルモードに戻る際（ESC / Ctrl+[）に IME を自動でオフにすることで、コマンド入力中に日本語入力が有効なままになってしまう事故を防ぎます。

## これは何？

日本語 IME を使っていると、以下のようなストレスがよくあります。

- 全角英数（Ａ・Ｚなど）で入力してしまい、コードや `hjkl` 移動、コマンドが効かなくなる
- カタカナ変換モードのまま気づかずコマンドを打ってしまう
- Vim で ESC / Ctrl+[ を押してノーマルモードに戻ったつもりが、IME がオンのままでキー操作が日本語入力に食われる

`input-police-deamon` はこれらを常時バックグラウンドで監視・矯正する「入力警察」です。タスクトレイに常駐し、ユーザーの作業を妨げずに IME の状態をパトロールします。

## 主な機能

- **全角英数の自動取り締まり**
  IME が「日本語入力オフ（英数モード）」なのに全角になっている場合、自動で半角に矯正します。
- **カタカナ入力の自動取り締まり**
  IME が「日本語入力オン」かつカタカナモードの場合、自動でひらがなモードに矯正します（全角・半角カタカナのどちらでも対象）。
- **Vim 用 IME 自動オフ**
  グローバルなキーボードフックで `ESC` および `Ctrl + [` を監視し、押された瞬間に IME を強制的にオフ（半角英数）にします。Vim でノーマルモードに戻る操作と同時に IME もオフになるため、「ノーマルモードのつもりが日本語入力のままだった」という事故を防げます。
- **タスクトレイ常駐**
  トレイアイコンから `Pause` / `Restart` で監視の一時停止・再開、`Exit` で終了ができます。
- **キー入力は奪わない**
  低レベルフックはあくまで監視用で、キーイベント自体は必ず次のフックへ渡します。他のアプリやショートカットの動作を妨げません。

## 動作環境

- Windows 専用（Win32 API / IME 制御 API に依存しています）
- [Tauri](https://tauri.app/) v2 + Rust + TypeScript 製

## 使い方

1. アプリを起動すると、タスクトレイに常駐します（ウィンドウは表示されません）。
2. 起動後は自動的に IME のパトロール・検問を開始します。特別な操作は不要です。
3. 一時的に機能を止めたい場合は、トレイアイコンを右クリックして `Pause` を選択します。再開する場合は同じメニューから `Restart` を選択します。
4. 終了する場合は、トレイアイコンのメニューから `Exit` を選択します。

## 開発・ビルド方法

`input-police-deamon` ディレクトリ内で以下を実行します。

```bash
# 依存関係のインストール
npm install

# 開発モードで起動
npm run tauri dev

# リリースビルド
npm run tauri build
```

## 仕組みについて（補足）

- IME の状態確認・変更には `WM_IME_CONTROL` メッセージを利用しています。
- Tauri（WebView2）のようにトップレベルウィンドウと実際にキー入力を受け取る内側のウィンドウが異なるケースがあるため、`AttachThreadInput` を使ってフォーカス中のウィンドウを解決し、IME 制御対象を正しく特定しています（フォアグラウンドウィンドウが変わったときだけ解決し直すことで負荷を抑えています）。
- ESC / Ctrl+[ の検知には `WH_KEYBOARD_LL`（グローバル低レベルキーボードフック）を使用しています。
