# Kana Cop

**Windows 用の日本語入力を補助するデーモン型アプリ。**
IME（日本語入力）の状態を裏で常時監視し、意図しない全角文字・カタカナ入力を強制的に矯正する。また、Vim でノーマルモードに戻る際（ESC / Ctrl+[）に IME を自動でオフにすることで、ノーマルモードに移行する際に日本語入力が有効なままコマンドが打てないイライラを解消する。

## What is this?

日本語 IME を使っていると、以下のようなイライラがある。

- 全角英数（Ａ・Ｚなど）で入力してしまい、コードや `hjkl` 移動、コマンドが効かなくなる
- カタカナ変換モードのまま気づかずコマンドを打ってしまう
- Vim で ESC / Ctrl+[ を押してノーマルモードに戻ったつもりが、IME がオンのままでキー操作が日本語入力に食われる

`Kana Cop` はこれらを常時バックグラウンドで監視・矯正するアプリで、タスクトレイに常駐し、ユーザーの作業を妨げずに IME の状態をパトロールします。

## What it does

- **全角英数の自動取り締まり**
  IME が「日本語入力オフ（英数モード）」なのに全角になっている場合、自動で半角に矯正。
- **カタカナ入力の自動取り締まり**
  IME が「日本語入力オン」かつカタカナモードの場合、自動でひらがなモードに矯正。（全角・半角カタカナのどちらでも対象）
- **Vim 用 IME 自動オフ**
  グローバルなキーボードフックで `ESC` および `Ctrl + [` を監視し、押された瞬間に IME を強制的にオフ（半角英数）にします。Vim でノーマルモードに戻る操作と同時に IME もオフになるため、「ノーマルモードのつもりが日本語入力のままだった」という事故を防げる。
- **タスクトレイ常駐**
  トレイアイコンから `Pause` / `Restart` で監視の一時停止・再開、`Exit` で終了の操作ができる。
- **キー入力は奪わない**
  低レベルフックはあくまで監視用で、キーイベント自体は必ず次のフックへ渡す。（他のアプリやショートカットの動作を妨げないように）

## Built with

- Windows 専用（Win32 API / IME 制御 API に依存）
- [Tauri](https://tauri.app/) v2 + Rust + TypeScript 製

## Getting started

リポジトリ直下で以下。

```bash
# 依存関係のインストール
npm install

# 開発モードで起動
npm run tauri dev

# リリースビルド
npm run tauri build
```

## Under the hood

- IME の状態確認・変更には `WM_IME_CONTROL` メッセージを `SendMessageTimeoutW`（`SMTO_ABORTIFHUNG`、100ms）で送る。相手アプリが応答なしでも待ち続けず、次の巡回で再試行する。
- Tauri（WebView2）や Teams のようにトップレベルウィンドウと実際にキー入力を受け取る内側のウィンドウが異なるケースがあるため、`GetGUIThreadInfo` でフォーカス中のウィンドウを解決し、IME 制御対象を特定する。相手の入力キューに相乗りしない軽い呼び出しなので、毎回解決し直してウィンドウ内のフォーカス移動にも追従できる。
- 自プロセスのウィンドウ（トレイメニューなど）が前面にあるときは何もしない。
- ESC / Ctrl+[ の検知には `WH_KEYBOARD_LL`（グローバル低レベルキーボードフック）を使用。フック内では IME オフ担当スレッドに依頼するだけで即座に戻り、実際の IME 操作は別スレッドで実行する。
- `tools/repro-hung-window.ps1` は、応答なしウィンドウに対する挙動確認用。
